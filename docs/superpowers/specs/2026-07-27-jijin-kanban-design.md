## 1. 概述

一个 Django 网站用于动态监控个人基金仓位变化、记录每日盈亏，并支撑长期的数据可视化与分析。录入采用**邮件驱动**：系统每日发邮件，用户点链接进批量录入页填盈亏，系统自动反推出每日总额、待确认金额、累计收益、收益率。

### 目标
- 准确记录每只场外基金每日盈亏与仓位变化（精确度对齐支付宝）
- 录入负担最小化（每天每只基金只录一个盈亏数）
- 数据可回溯、可校验、可补录
- 为未来的 AI 分析预留接口

### 非目标（MVP 不做）
- AI 助手（预留接口）
- 场内 ETF / 股票（数据模型预留扩展位）
- 自动抓取净值数据
- 精确的法定节假日日历（靠用户点「今日无交易」处理）
- 多币种汇率自动换算（美股基金先按 CNY 录）

## 2. 背景与核心问题

### 问题：历史每日盈亏怎么"像支付宝一样准"？

支付宝算得准，靠的是：①每次买卖的精确记录；②每只基金每天的历史净值（公开数据）。

**关键约束**：用户看不到过去的每日总额，只能提供：
- 某只基金**开始有收益的日子**（首次确认份额日）
- **每日定投额度**与**定投频率**
- **每日的当日盈亏金额**（支付宝「收益明细」可查）
- 每日的盈亏比例（选填）
- **起点总额**与**今天总额**（这两个能看到）

### 解决思路：录盈亏，反推总额

给定「起点总额 + 之后每天的盈亏 + 每天的投入」，可逐日累加反推出每一天的总额：

```
首日(start_date):   total = start_total
之后每天:           total = 前一天.total + profit + invested
```

总额口径 = **已确认 + 待确认**（即支付宝顶部显示的含待确认数字）。

### 6/1 端到端示例（A股，T+1，每日定投5元）

| 日期 | invested | profit(录) | has_trade | total(系统) | pending(系统) | 显示 |
|------|----------|-----------|-----------|------------|--------------|------|
| 6/1 起点 | 5 | —(基准) | True | 10.00 | 5 | `10.00（待确认 5）` |
| 6/2 | 5 | +0.84 | True | 15.84 | 5 | `15.84（待确认 5）` |
| 6/3 | 5 | +1.20 | True | 22.04 | 5 | `22.04（待确认 5）` |
| 6/4(周六) | 0 | — | False | 22.04(不动) | 0 | 休息日 |

- 6/1 总额 10 = 已确认 5（5/31 买入于 6/1 确认）+ 待确认 5（6/1 当天新定投）。
- **首日 profit 留空**（基准点，无前一天可比），盈亏从次日开始录。
- `start_total` 录的是当天支付宝顶部含待确认的数字（6/1 录 10）。

## 3. 核心数据模型

### User（扩展 Django AbstractUser）
| 字段 | 说明 |
|------|------|
| `email` | 唯一，注册时验证 |
| `email_verified` | 邮箱验证标记 |
| `mail_login_token` | 免密登录令牌（邮件链接携带，防伪造，定期刷新） |

### Fund（基金）
| 字段 | 说明 |
|------|------|
| `user` | 外键 |
| `name`, `code` | 基金名称、代码（代码可选） |
| `market` | A股 / 美股 |
| `confirm_delay` | 确认延迟天数（A股=1，美股=2）→ 决定待确认算法 |
| `invest_amount` | 定投额度 |
| `invest_frequency` | 每日 / 每周 |
| `invest_weekday` | 周几（仅"每周"时用） |
| `start_date` | 起购日 |
| `start_total` | 起点总额（用户录，含待确认） |
| `fund_type` | 股票型/混合/债券/指数/QDII/货币… |
| `risk_level` | R1–R5 |
| `currency` | CNY / USD |
| `is_active` | 是否仍在定投 |
| `tags` | 多对多 → Tag |

### Tag（标签）
- `user`、`name`（科技/消费/新能源…，自由添加，保证可扩展）

### DailyRecord（每日记录）★ 核心
| 字段 | 说明 |
|------|------|
| `fund`, `date` | 联合唯一（一只基金一天一条） |
| `profit` | 当日盈亏（用户录） |
| `profit_ratio` | 当日盈亏比例（选填，校验用） |
| `invested` | 当日投入（按定投预填，可改） |
| `total` | 反推总额（系统算） |
| `pending` | 待确认金额（系统算） |
| `has_trade` | True=有交易录了 / False=今日无交易（休息日/未响应自动标记） |

> 多只基金天然支持：每天每只基金一条 DailyRecord。

## 4. 计算逻辑（`funds/services.py` 纯函数，易测）

### ① 反推每日总额
```
首日:    total = start_total
之后:    total = 前一天.total + profit + invested
```

### ② 待确认自动算（最近 N 天未确认的投入，N = confirm_delay）
```
T+1(A股):  pending = 当天 invested
T+2(美股): pending = 今天 + 昨天 的 invested
通用:     pending = sum(invested[d] for d in [date-N+1 ... date])
```
显示 `"总额（待确认 X）"`，X = pending。

### ③ 两层校验
- **比例校验**：用户填的 `profit_ratio` vs 系统算的 `profit ÷ 前一天.total`，超容差（默认 ±0.5%）→ 提醒"可能抄错"。
- **总额校验**：用户随时可录「今天总额」(`current_total`)，系统反推到今天的 `total` 应≈它，对不上 → 定位错误时间段。

## 5. 录入流程（邮件驱动）

### 每日阶梯提醒（一日三次）
```
crontab 三个时间点跑同一 management command：
  18:00  → 今天未录入？发第 1 次
  21:00  → 还未录入？发第 2 次（标注"第二次提醒"）
  23:00  → 还未录入？发第 3 次
  23:30  → finalize：仍无动静 → 该用户所有基金今天自动 has_trade=False
```
- **「已录入」判定**：今天保存过任意一条记录，或点过「今日无交易」→ 不再催。
- **finalize**：三次未响应，系统补 `has_trade=False`，日历显示「无交易」而非「缺失」。后续可补录覆盖。
- **周末**：只发一次「周末愉快」（周六/周日系统可识别）。
- 法定节假日：系统按工作日发邮件，用户点「今日无交易」处理。

## 6. 认证

- **注册**：填邮箱 → 系统发验证邮件 → 点击 → `email_verified=True`。
- **免密登录（magic link）**：每日邮件链接形如 `https://域名/daily/?token=<mail_login_token>`，点开 → 后端校验令牌 → 自动登录 → 跳当日批量录入页。令牌定期刷新，对用户透明。
- 信任基础：邮件发到注册时已验证的邮箱，能收到者即用户本人。

## 7. 页面与交互

### ★ 每日批量录入页（邮件链接落点）
一次列出用户所有基金，批量填、一键保存：

```
今日录入 · 2026-07-27（周一）              [ 今日无交易 → ]

┌─ 你的基金 ──────────────────────────────────────┐
│ 基金          今日投入    今日盈亏    比例(选填)  │
│ ─────────────────────────────────────────────── │
│ A基金(每日5)   [ 5.00]    [+0.84]    [ 0.83% ]   │
│ B基金(每日10)  [10.00]    [+1.20]    [       ]   │
│ C基金(每周50)  [ 0.00]←今天非定投日,可改 [     ]  │
│ ─────────────────────────────────────────────── │
│             [ + 添加新基金 ]                      │
│             [ 💾 保存今日全部 ]                   │
└─────────────────────────────────────────────────┘
   提示: A基金比例校验不通过(你填0.83%,系统算0.85%) ⚠️
```
- 今日投入自动预填定投额；非定投日预填 0，可改（加仓）。
- 比例校验实时反馈。
- 「今日无交易」一键标记当天休息。
- 「+添加新基金」当场加，加完回录入页继续。
